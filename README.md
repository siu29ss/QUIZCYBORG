# QUIZCYBORG 🧠⚡

A dynamic, interactive quiz application built using HTML, CSS, and JavaScript. QUIZCYBORG offers a sleek interface and fast-paced question delivery to test your knowledge in a fun and engaging way.

## 🚀 Live Demo

👉 [Try QUIZCYBORG Now](https://siu29ss.github.io/QUIZCYBORG/)

---

## 🛠️ Tech Stack

- **HTML** – Structure of the web application
- **CSS** – Styling and layout (responsive design)
- **JavaScript** – Core quiz logic, interactivity, and dynamic rendering

---

## 🎯 Features

- ✅ Multiple choice questions
- ✅ Score tracking
- ✅ Instant feedback on correct/wrong answers
- ✅ Timer for added challenge
- ✅ Responsive layout – works across devices

---

## 📂 Project Structure

```
QUIZCYBORG/
│
├── index.html          # Main HTML structure
├── style.css           # Styling for the app
└── script.js           # Quiz logic and interactivity
```

---

## 📦 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/siu29ss/QUIZCYBORG.git
   ```
2. Open `index.html` in your browser.

No build tools or dependencies required – it's 100% vanilla JS.
